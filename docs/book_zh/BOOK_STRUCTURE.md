# xv6 中文学习手册 - 章节结构

## 前言
- xv6简介及其教学意义
- 本书结构和阅读建议

## 第一部分：基础与引导
### 第1章：操作系统概述与xv6背景
- 常见操作系统概念 (内核态/用户态, 系统调用, 进程, 内存管理等)
- xv6设计哲学与Unix V6渊源
- 搭建xv6实验环境

### 第2章：启动过程与系统初始化
- PC启动流程概览 (BIOS, MBR)
- `bootasm.S`：进入保护模式
- `bootmain.c`：加载内核
- `main.c`：内核初始化序列
    - 多处理器启动 (`startothers`)

## 第二部分：核心机制
### 第3章：内存管理
- 物理内存管理 (`kalloc.c`)
    - 页帧分配与释放
- 虚拟内存管理 (`vm.c`)
    - 分页机制：页目录与页表
    - 内核地址空间布局
    - 用户地址空间创建与管理

### 第4章：进程管理
- 进程概念 (`struct proc`)
- 进程生命周期与状态转换
- 进程创建 (`fork`)
- 程序加载与执行 (`exec`)
- 进程终止 (`exit`) 与等待 (`wait`)
- 调度 (`scheduler`)
- 上下文切换

### 第5章：中断、异常与系统调用
- 中断与异常机制 (`trap.c`)
    - 中断描述符表 (IDT)
    - 陷阱处理流程
    - 页面错误处理
- 系统调用接口 (`syscall.c`)
    - 系统调用分发
    - 参数传递
- APIC详解 (`lapic.c`, `ioapic.c`)

### 第6章：并发与同步
- 并发带来的挑战
- 锁 (`spinlock.c`)
    - 自旋锁的实现与使用
- 睡眠锁 (`sleeplock.c`)
    - 阻塞等待与唤醒

## 第三部分：文件系统
### 第7章：文件系统抽象
- 文件与目录
- 文件描述符与打开文件表 (`file.c`)
- Inode (`fs.c`)
- 路径名解析

### 第8章：文件系统实现
- 磁盘块管理与缓冲缓存 (`bio.c`)
- 日志系统 (`log.c`)
- 磁盘驱动 (`ide.c`)
- 实际文件操作流程 (读/写/创建)
